proto_3.ipynb -> is the most advanced version of my implementation of the NN from scratch including in this order :
- the design of the NN 
- the importation and the processing of the dataset
- the training of the model
- the estimation of the performance metrics.

PoC_video_extraction.ipynb -> is the processing of the test videos, cutting them into frames.

PoC.ipynb -> is the test of the models on the frames of the videos, the frames are then reassembled into a video.

The dataset is not included because he is large but it can be easily found : Mehdi Özel. Drone dataset. GitHub repository, 2021.

Some of the trained models are included as examples.
